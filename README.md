# Meu Portfólio

## Sobre o projeto

Projeto pessoal desenvolvido para apresentar minha trajetória na área de desenvolvimento de software, meus conhecimentos, formação acadêmica e projetos.

O portfólio reúne informações profissionais, demonstrações dos projetos desenvolvidos e formas de contato.

**Acesse:** [Meu Portfólio](https://joaopedro-moreira.github.io/Meu-Portifolio/)

## Objetivo

Desenvolver uma página pessoal para centralizar minha apresentação profissional e facilitar o acesso aos meus projetos e canais de contato.

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Funcionalidades

- Apresentação pessoal e profissional.
- Navegação entre seções da página.
- Carrossel interativo para exibição dos projetos.
- Demonstrações em vídeo dos projetos.
- Seção de formação acadêmica.
- Apresentação dos conhecimentos e tecnologias.
- Links para GitHub, LinkedIn e email.

## Como executar

**Acesse pelo navegador:**

[Meu Portfólio](https://joaopedro-moreira.github.io/Meu-Portifolio/)

**Para executar localmente:**

1. Clone o repositório:

   ```bash
   git clone https://github.com/JoaoPedro-Moreira/Meu-Portifolio.git
   ```

2. Abra a pasta do projeto.
3. Execute o arquivo `index.html` em um navegador.

## Aprendizados

- Estruturação de páginas com HTML.
- Estilização e responsividade com CSS.
- Manipulação de elementos e interações com JavaScript.
- Organização de arquivos e recursos de um projeto web.
- Versionamento e publicação utilizando GitHub e GitHub Pages.
